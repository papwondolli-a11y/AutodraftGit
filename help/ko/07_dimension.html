구멍 콜아웃

구멍의 사양(지름, 개수, 깊이 등)을 지시선으로 표기합니다.


키보드 명령

Holecallout

아이콘 클릭

단축 명령

Ha



   Command : Holecallout

   콜아웃을 표기할 구멍을 선택 하세요 (완료: 우클릭/엔터) : 구멍객체 선택

   콜아웃을 표기할 구멍을 선택 하세요 (완료: 우클릭/엔터) :

   --- 구멍 객체를 선택 합니다. 구멍 객체는 “그리기” 탭 “구멍R” 또는 “구멍P”의해

       생성된 객체 이어야 합니다. 선택된 구멍 개수 만큼 숫자가 자동 기입됩니다.

   지시선 시작점을 지정 하세요 :

   지시선 끝점(문자 위치)을 지정 하세요 :

   콜아웃을 표기할 구멍을 선택 하세요 (완료: 우클릭/엔터) :

   --- 지시선 위에 문자는 문자를 더블클릭 하여 수정 할 수 있습니다.


Tip : 구멍 객체와 구멍 단면객체, 구멍속성창, 구멍 콜아웃은 연동 됩니다.


   --- 구멍 객체를 선택 하면 오른쪽 속성 목록창에 선택괸 구멍 객체의 속성값이

        표시 됩니다.

        구멍객체 속성창과 “치수선” 탭의 “구멍 콜아웃” “그리기” 탭의 “구멍단면” 연동이 됩니다.

        예를 들어 콜라웃 지시선 위의 글자 “M10x1.6-6Hx15DP”를 M10x1.6-6Hx20DP 탭 가공

        깊이를 변경할 경우 현재 도면에서 변경된 구멍의 단면 객체가 존재 할 경우

        자동으로 체크하여 갱신 여부를 결정 할 수 있습니다. 같은 방법으로

        속성창과 콜아웃 문자에서 M10를 M20으로  변경할 경우 구멍객체와 구멍객체에

        연결된 구멍 단면이 자동 갱신 됩니다.

        이 처럼 속성창과 콜라웃을 편집 하면  도면 객체에 적용되도록 되어 있습니다.
