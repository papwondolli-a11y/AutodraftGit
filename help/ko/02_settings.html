환경설정

도면 환경, 화면에 표시되는 패널, 언어, 테마 등을 설정합니다.

도면설정


키보드 명령

Limits

아이콘 클릭

단축 명령

Li

도면 용지 크기, 도면틀(한계) 등 도면 전반의 설정을 엽니다. "보기" 탭의 "도면틀"과 같은 다이얼로그입니다.

도면틀 크기 : 일반틀, 사용자틀 선택 합니다.

  • 일반틀 : 선택한 크기로 가상틀(테두리)이 생성 됩니다.
  • 사용자틀 : 선택한 크기의 도면틀이 블록으로 삽입 됩니다.
    삽입되는 블록의 위치는 “./frames” 입니다.
    블록 이름은 A0,A1,A2,A3,A4 입니다.
    도면틀 변경을 원하면 이곳의 파일을 오픈 하여 수정 하여 재 저장 하시면
    사용자가 원하는 도면틀을 사용 할 수 있습니다

도면 스케일 : 원하는 스케일을 선택 또는 입력이 가능 합니다.

단위 : mm와 inch를 선택 할 수 있습니다.

중심선 레이어 설정 : 도면에서 중심선에 사용할 레이어를 설정 할 수 있습니다.

치수 설정



키보드 명령

Dimstyle

아이콘 클릭

단축 명령

DS


치수 문자 크기, 화살표 모양, 단위 등 치수 스타일을 설정합니다. "치수선" 탭의 "스타일"과 같은 다이얼로그입니다.

   ① : 치수보조선 돌출 크기

   ② : 치수 보조선 간격 띄기

   ③ : 치수선 간격

   ④ : 치수선 글자 띄기

언어 / Language

한국어 / English UI를 전환합니다. 변경 사항은 프로그램을 재시작해야 반영됩니다.

보기 메뉴 — 화면 요소 표시

  • 명령어 라인 보기 — 하단 명령어 입력창 표시 여부
  • 명령어 필터 보기 — 명령어 검색/필터 창 표시 여부
  • 선 두께 보기 — 화면에서 선 굵기를 실제 두께로 표시할지 여부
  • 선 종류 도크 — 선 종류(라인타입) 팔레트 도크 표시 여부
  • 레이어 테이블 — 레이어 관리 도크 표시 여부
  • 블록 팔레트 — 블록 라이브러리 팔레트 도크 표시 여부
  • 속성 도크 — 선택한 객체의 속성 패널 표시 여부
