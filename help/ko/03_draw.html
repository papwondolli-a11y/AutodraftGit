L

command : line
  시작점을 지정하세요 :   화면에서 첫번째 점(P1) 클릭

다음점을 지정 하세요 또는 [Undo] :  다음 점 입력은 아래 5가지 방법중 선택

   1. 화면 다른 한곳(P2) 지정(마우스 좌클릭)    결과 : P1-P2 라인 생성

   2. 거리<각도 또는 거리d각도
     ex) 다음 점을 지정 하세요 또는 [Undo ] : 50<45 또는 50d45
     P1 점에서 거리 50mm 각도 45도 인 좌표지점(p2)

   3. Ortho(F8) 활성화 상태에서 숫자 입력
     ex) 다음 점을 지정 하세요 또는 [Undo ] : 50
     P1 점에서 마우스 포인터(크로스헤어) 있는 수평,수직 방향으로 거리 50mm 방향 좌표지점(p2)

   4. Ortho(F8)비 활성화 상태에서 숫자 입력
     ex) 다음 점을 지정 하세요 또는 [Undo ] : 50
     P1 점에서 마우스 포인터(크로스헤어) 있는 방향으로 거리 50mm 방향 좌표지점(p2)

   5. 절대값 입력
     ex) 다음 점을 지정 하세요 또는 [Undo ] : 100,150

HA

                                 설정 하거나 약간 작게 설정 합니다다.

    3. 각도를 설정 합니다.

    4. 선택 형태 선택 : 아래 설명

    5. 레이어를 선택 합니다.


    *** 선택 형태 ***

     1. 상자모양 선택 : 간단한 형태의 도형에 해치시 유용합니다.

     사각상자 모양의 첫번째 점을 지정 하세요 :  p1

     사각상자 모양의 두번째 점을 지정 하세요 :  p2

     --- p1, p2 형성된 상자모양의 안쪽에 해칭이 됩니다.


     


     2. 복합모양/해치공간선택 :

     사각상자 모양의 첫번째 점을 지정 하세요 :  p1

     사각상자 모양의 두번째 점을 지정 하세요 :  p2

     해칭이될 내부공간을 지정하세요 : p3

      --- p1, p2 형성된 사각형 공간에서 닫힌 공간을 찾고 p3을 포함한 공간에 해칭을 합니다.
