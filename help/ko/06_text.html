글자쓰기

도면에 문자를 입력하는 도구입니다.

여러줄

여러 줄로 이루어진 문단 형태의 텍스트를 입력합니다.


키보드 명령

Text

아이콘 클릭

단축 명령

Tt


   Command : text

   글자 시작 점을 지정 하세요 :

   글자를 입력 하세요 (종료 : 입력란 외부를 클릭 하세요) :

    --- 글자 편집은 글자를 더블 클릭 하면 됩니다.

한줄

한 줄짜리 텍스트를 입력합니다.


키보드 명령

Dtext

아이콘 클릭

단축 명령

Dt


   Command : dtext

   글자 시작 점을 지정 하세요 :

   글자를 입력 하세요 (종료 : 엔터) :

    --- 글자 편집은 글자를 더블 클릭 하면 됩니다.

박스글자

테두리 박스 안에 문자를 입력합니다.


키보드 명령

Boxtext

아이콘 클릭

단축 명령

Tb


   Command : boxtext

   글자 시작점을 지정하세요 [Pick/Setup] :

   글자를 입력 하세요 (종료 : 엔터) : 글자입력

   --- 글자를 쓰고 엔터를 입력 하면 쓰여진 글자에 테두리가 생성 됩니다.

   <옵션 Pick>

    --- 기존 문자를 선택하면 사각 테두리가 생성 됨니다.

   글자 시작점을 지정하세요 [Pick/Setup] : p

   박스를 만들 문자 선택 : 기존 문자 선택

   < 옵션 Setup >

   글자 시작점을 지정하세요 [Pick/Setup] : s


   박스 레이어 : 사각 테두리 레이어를 설정 합니다.

   글자 레이어 : 글자 레이어를 설정 합니다.

   기존 글자 레이어 적용 체크박스 : Pick에 의해 선택되어지는 글자에 글자레이어에

                                            설정된 레이어를 적용 합니다.

   박스 크기 연동 : 박스(테두리)가 있는 글자를 편집(글자 더블 클릭) 하면 글자 크기에

                       맞춰 박스 크기가 자동 변경를 설정 합니다.
