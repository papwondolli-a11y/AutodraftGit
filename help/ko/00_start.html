AutoDraft 사용자 매뉴얼

이 매뉴얼은 AutoDraft의 메뉴/탭바에 있는 기능들을 순서대로 정리한 문서입니다. 왼쪽 목차에서 항목을 클릭하면 해당 설명으로 바로 이동합니다.

화면 구성

화면은 크게 다음 영역으로 구성됩니다.

① : 타이틀바(TitleBar)
② : 메뉴바(MenuBar)
③ : 탭바(TabBar)
④ : 툴바(ToolBar)
⑤ : 글자,레이어 설정 콤보(T/L Combo)
⑥ : 도면명 탭(DrawingName Tab)
⑦ : 데시보드(DashBoard)
⑧ : 도크창(Dock Window)
⑨ : 커멘드도크창(Command Dock Window)
⑩ : 상태바(StaturBar)

  • 메뉴바 — 파일, 옵션, 보기, 설정, 도움말 등 전체 메뉴
  • 탭바 — 그리기, 편집하기, 보기, 글자쓰기, 치수선, 다중선, 블록, 기계부품, 평면도어/창문 등 기능별로 묶인 도구 버튼
  • 도크(패널) — 선 종류, 레이어 테이블, 블록 팔레트, 속성 도크 등 (보기 메뉴에서 표시 여부 전환 가능)
  • 명령어 라인 / 명령어 필터 — 하단에서 명령어를 직접 입력하거나 검색

타이틀바

AutoDraft 타이틀바 에는 5개의 아이콘 메뉴와 AutoDraft (빌드된 날짜) 표시되어 있습니다.

: 파일을 저장 합니다.

: 다른 이름으로 저장 합니다.

: Redo 합니다.

: Undo 합니다.

: 현재 도면을 출력 합니다.

데시보드

  • 위치찾기 : 파일(.cdb)위치를 찾습니다.
  • 최근항목 : 최근 사용된 파일 목록(.cdb)을 보여줍니다.
  • 폴더 전체 항목 : 위치 찾기에서 선택된 폴더 전체 목록(.cdb) 보여줍니다.
  • 원형도면 : 원하는 원형 도면을 선택 합니다.
  • 전체 삭제 : 최근 항목 에 표시된 항목을 모두 삭제(초기화) 합니다.
  • 미리보기 변경 : 큰아이콘, 작은 아이콘 토글 방식으로 변경 합니다.

최근항목, 전체 항목 미리보기 아이콘을 더블클릭 하여 오픈 할 수 있습니다.

최근항목 도면 미리보기 아이콘을 마우스 우클릭 하여 항목에서 제거 할 수 있습니다.

도크(고정창)

도크창(고정창)은 화면 오른쪽 길게 보이는 부분이며 현재 4개의 도크창을 가지고 있습니다.

1. 라인타입 목록 : 라인타입을 관리 합니다,

  • 새로운 라인타입을 만들 수 있습니다.
  • 기존 라인타입을 편집할 수 있습니다.
  • 선택된 라인타입을 삭제 합니다.
  • 현재 라인타입을 저장 합니다.

2. 레이어 목록 : 레이어를 관리 합니다.

  • 새로운 레이어를 만들 수 있습니다.
  • 선택된 레이어을 삭제 합니다.
  • 선택된 레이어를 현재 레이어로 활성화합니다.
  • 레이어 이름 변경 : 이름 필드 더블클릭
  • 색상, 선 두께, 라인타입 변경 : 각 필드 클릭

레이어 도크와 레이어 콤보 박스는 연동되고 있고, 레이어 콤보 박스를 통해 현재 레이어 변경 가능 합니다.

3. 블록 목록

  • Wblock에 의해 만들어진 블록을 표시하는 도크 입니다.
  • 미리보기 아이콘에서 원하는 블록을 더블클릭으로도면에 삽입합니다.

4. 속성 목록

  • 선택된 객체의 속성값을 관리 합니다.
  • 레이어, 치수선 공차.. 등 속성창에서 값을 변경하면 도면에 실시간 반영 됩니다.

그립/크로스헤어

AutoDraft의 크로스헤어는 위의 이미지 처럼 생겼습니다.

십자선 중앙의 네모가 선택 상자 입니다. 객체 선택시 네모 상자에 걸치도록 해야 객체가 선택 됩니다.

예를 들어 라인 객체를 선택 하면 위의 이미지 처럼 하늘색과  파란점 3개(객체에 따라 점의 개수가 다름) 로

선택 되었음을 표시 합니다. 여기서 파란점을 그립 마커라고 합니다.

마우스를 이동 하여 크로스헤어의 선택 상자을  그립마커 위로(상자 안쪽으로 들어가도록) 가져가면

그립마커 색상이 빨간색으로 변하는 것을 볼 수 있습니다.

그립 마커 색상이 빨간색 일때 마우스 좌클릭 하여 이동 하면 이동 경로에 따라 객체 모양이

변형 되는 것을 볼 수 있읍니다. 그것을 그립 기능이라 하며 그려지는 모든 객체에 적용되는

기본 기능 입니다.

명령어가 없는 상태(command: 상태) 에서 선택된 모든 객체는 그립 표시가되고 (다중 선택도 가능

하지만 그립표시는 5개 까지로 제한되어 있습니다.) 왼쪽 속성목록창에 선택된 객체의 정보가

표시 됩니다. 그립 해제 키는 ESC 키 입니다.
