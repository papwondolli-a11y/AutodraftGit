이동

선택한 객체를 지정한 방향/거리만큼 이동합니다.


키보드명령

Move

아이콘 클릭

단축명령

M

   Command : move

  객체를 선택 하세요 : 화면에서 객체 선택


*** 객체 선택 방법 (공통사항) ***

1. 크로스헤어  안 네모 박스로 하나씩 선택

2. 객체가 없는 빈 공간을 클릭(p1)하고 마우스를 움직이면 상자 모양의 공간이 생김

    점 P1에서 왼쪽으로 이동시 : 초록색 상자가 생기고 초록색 공간과 접촉이 있는 모든 객체 선택

   점 P1에서 오른쪽으로 이동시 : 파란색 상자가 생기고 파란색 공간 안에 완전히 포함된 객체 선택

3. 선택 해제 : 선택된 객체를 다시 선택하면 선택 해제가(토글방식) 됩니다.

  객체를 선택 하세요 : < 선택 종료: 스페이스, 엔터, 마우스우클릭>

  기준점을 지정 하세요 : 기준점 지정

  목표점을 지정 하세요 : 목표점 지정(앞서 라인명령 처럼 좌표점 입력이 가능)

   --- R값 변경은 변경하는 숫자만 바로 입력해도 되고 “R”엔터 후

       R값을 입력 하세요 <0>: 에서 입력 하셔도 됩니다.

   <R값 입력시 예 : 10 입력시>

   첫번째 객체를 선택 하세요 (Radius=10) [Radius]: [R] : R값 변경 ,종료= 엔터, 스페이스

   --- R값 변경 다른 객체 선택, 엔터및 스페이스로 종료

 

< R값 0 인 경우>

     첫번째 객체를 선택 하세요 (Radius=0) [Radius]: [R] :  객체 선택

     두번째 객체를 선택 하세요 : 객체 선택

      ---- Radius=0 에 지정된 값으로 모따기를 진행 합니다.

      ---- 초기값이 0 일때는 두직선이 만나게 됩니다.

TIP :  1.  선택하세요 : 물음이 있기 때문에 객체가 없는 빈공간을 클릭한
            “Crossing”으로 객체 선택이 가능 합니다.

        2. 첫번째 객체를 선택 하세요 (Radius=10) [Radius]: [R] :
           객체 선택시 shift 를 누르고 객체를 선택 하면 선자르기가 진행되지 않습니다.
