파일

도면 파일을 새로 만들거나 열고, 저장하고, 다른 CAD 포맷과 주고받는 기능입니다.

새로만들기 (Ctrl+N)

빈 새 도면을 엽니다.

템플릿 보기... (Ctrl+Shift+N)

등록된 템플릿 목록에서 하나를 선택해 새 도면을 시작합니다.

  • 만들기 : 새로운 템플릿(원형도면)를 만들 수 있습니다.
  • 교체 : 선택된 템플릿을 기본 템플릿으로 사용합니다.
  • 편집 : 선택된 템플릿을 수정합니다.
  • 삭제 : 선택된 템플릿을 삭제합니다.
  • 취소 : 템플릿 보기를 취소합니다.

템플릿으로 저장...

현재 도면을 템플릿으로 저장해, 이후 "템플릿 보기"에서 재사용할 수 있게 합니다.

열기 (Ctrl+O)

저장된 도면 파일(.cdb 등)을 엽니다.

저장하기 (Ctrl+S)

현재 도면을 같은 파일에 저장합니다.

다른이름 저장하기 (Ctrl+Shift+S)

현재 도면을 새 파일 이름으로 저장합니다.

일괄 출력...

여러장의 도면중 원하는 도면을 선택하고 지정된 순서에 따라 일괄 출력합니다.

① : 출력할 파일 타입을 설정 합니다.
② : 폴더를 선택 합니다.
③ : 다른 폴더 추가 버튼 입니다.
④ : 선택된 폴더 초기화 버튼 입니다.
⑤ : ②에서 선택된 폴더에 있는 파일이 표시됩니다.
⑥ : ⑤ 에서 선택된 파일 미리보기 창입니다.
⑦ : 미리보기 창에 있는 파일을 출력 리스트에 추가 하는 버튼 입니다.
⑧ : 프린터 대기파일 창 입니다
⑨ : 출력 리스트에서 선택된 파일을 제거 합니다.
⑩ : 출력파일 순서 변경 버튼 입니다.

출력 스타일 편집...

인쇄 시 흑백과 컬러 출력 스타일을 지정 합니다.

** 출력기(프린터)가 흑백인 경우 **
---- 출력 스타일을 흑백으로 설정 하여야 합니다.
---- 컬러로 설정할 경우 선이 흐리게 출력 됩니다.
** 출력기가(프린터)가 컬러일 경우> **
---- 컬러로 설정 하면 레이어에 설정된 컬러로 출력 됩니다.
---- 흑백으로 설정 하면 검정색 으로 출력됩니다.

DXF 가져오기...

다른 CAD 프로그램에서 만든 DXF 파일을 불러옵니다.

DXF 내보내기...

현재 도면을 DXF 파일로 저장해 다른 CAD 프로그램과 호환되게 합니다.

DWG 가져오기...

AutoCAD DWG 파일을 불러옵니다.

끝내기 (Alt+F4)

프로그램을 종료합니다.
