AutoDraft 사용 안내
==================

AutoDraft 는 기계·건축 도면을 그리는 2D CAD 입니다.

[실행 방법]
1. 이 폴더(AutoDraft)를 원하는 곳에 두세요. (예: C:\AutoDraft)
2. AutoDraft.exe 를 더블클릭하세요. 별도 설치는 필요 없습니다.

[필요한 환경]
- Windows 10 / 11 (64비트)

[처음 실행할 때 "Windows가 PC를 보호했습니다" 화면이 나오면]
이 프로그램은 코드 서명이 없어서 나타나는 경고입니다.
"추가 정보" -> "실행" 을 누르면 실행됩니다.

[폴더 안의 파일]
- AutoDraft.exe      프로그램 본체
- Data, blocks, frames, tools   프로그램이 사용하는 자료 (지우지 마세요)
- TERMS.txt          사용 조건 (무료 사용, 재배포 가능)
- NOTICE.md          함께 쓰인 오픈소스 고지
